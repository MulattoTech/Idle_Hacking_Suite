# Idle Hacking Suite 2.0 Regression Report

## Basis

The 2.0 implementation was developed from the v1.11 runtime plus a sanitized fixture derived from the September 17, 2026 capture. The short capture exposed current first-party client/protocol structures for Breach, Hacking, Hardware, Homelab, Marketplace, Contracts/Events-related schemas, and the changelog endpoint.

## Cross-system regression scenarios

The integration harness covers:

1. Marketplace background scanning yields to a time-sensitive Event join through the central governor.
2. A Breach ready reset immediately produces a high-priority ready action.
3. A completed contract around a board reset is claimed/reconciled and the next contract is selected without waiting for the generic master interval.
4. Enhancement spending stops when reserve/budget rules would be crossed.
5. A rate-limit signal suppresses optimizer/market/enhancement sends until the governor recovery point.
6. An available Homelab build slot receives the next legal planned job.
7. A measured post-optimizer performance regression produces a rollback/re-optimization recommendation rather than blindly retaining the previous winner set.

## Soak simulation

An accelerated deterministic two-hour simulation runs 480 fifteen-second ticks with:

- recurring marketplace background work;
- Event join windows;
- Breach ready resets;
- Contract board reset behavior;
- injected rate limits;
- crafting-resource depletion and reserve blocking.

The harness asserts action deduplication, bounded sends, queue recovery, and no uncontrolled retry storm.

## Release validation

The final pre-package suite contains **73 automated tests**, including the seven cross-system regressions and the accelerated **480-tick / two-hour** soak simulation.

Release packaging additionally verifies:

- JavaScript syntax for all runtime/test modules;
- valid `manifest.json` with version `2.0.0`;
- every manifest-referenced runtime file exists;
- popup/dashboard JavaScript element references exist in their HTML;
- popup/dashboard element IDs are unique;
- packaged icon sizes are square/valid;
- diagnostic sanitizer removes credential-shaped fields;
- September 17 regression fixture contains no credential-shaped fields;
- final ZIP archive integrity.

## Known limitations

**Direct Resource Store purchasing:** not implemented because the short September 17 capture did not expose a verified current Resource Store purchase protocol. Resource Strategy is advisory/cross-system in 2.0. Hardware and Homelab direct automation are implemented using captured current protocols.

**Changelog body:** the capture identified `/content/changelog`, but the response body was omitted. The runtime parser therefore validates/parses the live endpoint and fails visibly if the current markup is unsupported.

**Optimization optimality:** adaptive decisions use observable combat outcomes and transparent heuristics; they are not a mathematical proof of global optimum.

**Breach native auto-talents:** current first-party auto-allocation may require an in-game Premium entitlement. Suite extension allocation is the fallback.
